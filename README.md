# Фантомный блок (phantom-block)

Fabric-модификация для Minecraft Java Edition 1.21.1. Мод добавляет блок «Фантомный блок»: он имеет собственную текстуру и модель, доступен в группе строительных блоков и создаётся по рецепту. Коллизия блока пустая — игрок может проходить сквозь него. При нажатии ПКМ по установленному блоку в чат выводится сообщение «Блок-призрак активирован!».

## Совместимость

- Minecraft Java Edition: **1.21.1**
- Fabric Loader: **0.20.1 или новее** (в `fabric.mod.json` указано `>=0.20.1`)
- Fabric API: **0.116.17+1.21.1**
- Java: **21 или новее**
- Gradle: сборка через Gradle Wrapper проекта

Используйте указанные версии как проверяемую целевую конфигурацию. Совместимость с другими версиями Minecraft не заявляется.

## Установка готового мода

1. Установите Minecraft Java Edition 1.21.1.
2. Установите Fabric Loader совместимой версии и Fabric API `0.116.17+1.21.1`.
3. Запустите игру один раз с Fabric, чтобы появилась папка `mods`.
4. Скопируйте основной файл `phantom-block-1.0.0.jar` в каталог `mods` профиля Minecraft.
5. Запустите игру и проверьте, что мод загружен. В творческом режиме найдите «Фантомный блок» в группе «Строительные блоки» либо проверьте рецепт ниже.

> Если имя JAR после сборки отличается, используйте фактическое имя файла из `build/libs`. Не устанавливайте файлы `*-sources.jar` или `*-dev.jar`.

## Получение и использование

### Творческий режим
«Фантомный блок» зарегистрирован в группе «Строительные блоки» (Building Blocks).

### Выживание — рецепт крафта
Рецепт: 4 каменных кирпича и 1 жемчужина Края, размещённые по шаблону:

```text
[   ] [Каменные кирпичи] [   ]
[Каменные кирпичи] [Жемчужина Края] [Каменные кирпичи]
[   ] [Каменные кирпичи] [   ]
```

Результат — 1 Фантомный блок.

### Поведение
- Блок имеет собственную текстуру 16×16 и модель куба.
- Игрок проходит сквозь блок (пустая форма столкновения).
- В коде задана непрозрачность 15.
- При нажатии ПКМ по установленному блоку сервер отправляет игроку сообщение: «Блок-призрак активирован!».

## Сборка из исходников

Требуется JDK 21. В Windows откройте терминал в корне репозитория и выполните:

```bat
.\gradlew.bat clean build
```

Успешный результат сборки — сообщение `BUILD SUCCESSFUL`. Основной артефакт ищите в `build/libs/`. Перед передачей проверьте, что выбран основной remapped JAR, а не `-dev` или `-sources`.

## Проверка перед выпуском

1. Собрать проект командой `clean build`.
2. Установить основной JAR в отдельный профиль Minecraft 1.21.1 с Fabric Loader и Fabric API.
3. Удалить старую копию этого мода из `mods`, чтобы не загрузить прежнюю версию.
4. Проверить загрузку мода, наличие блока, рецепт, прохождение сквозь блок и сообщение по ПКМ.
5. Сохранить скриншоты успешной сборки и работающего объекта в отчёт.

## Известные ограничения

- Поддержка заявлена только для Minecraft 1.21.1.
- Дополнительное поведение при ПКМ ограничено сообщением в чате.
- Хотя в проекте есть Block Entity и поле сохранения состояния другого блока, README не заявляет копирование/подмену внешнего блока как реализованную пользовательскую функцию: в доступной логике нет процедуры заполнения `copiedState`.
- Результат проверки установленного итогового JAR следует фиксировать только после фактического тестирования на целевом профиле.
